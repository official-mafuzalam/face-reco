# ১. ইনস্টলেশন ও সেটআপ (Windows)

এই গাইড অনুসরণ করে একটি নতুন Windows পিসিতে গেট ফেস বসানো যাবে। প্রতিটি কমান্ড **PowerShell**-এ, প্রজেক্ট ফোল্ডারের ভেতর থেকে চালাতে হবে।

## সহজ ইনস্টল (ZIP থেকে, পরামর্শ দেওয়া পদ্ধতি)

1. ডেভেলপারের দেওয়া `GateFace-<তারিখ>.zip` ফাইলটি নতুন পিসিতে কপি করুন।
2. একটি সহজ জায়গায় আনজিপ করুন, যেমন `C:\GateFace`। (ডেস্কটপ বা Downloads নয়, আর ফোল্ডারের নামে বাংলা অক্ষর নয়।)
3. ফোল্ডারের **`Install.bat`**-এ **ডান-ক্লিক → Run as administrator**।
4. কালো উইন্ডোতে প্রশ্নগুলোর উত্তর দিন (Enter চাপলে বন্ধনীর বড় অক্ষরের উত্তরটি নেওয়া হয়):

| ইনস্টলার নিজে যা করে | আপনাকে যা জিজ্ঞেস করে |
|---|---|
| Python 3.11 / 3.12 খোঁজে; না থাকলে ইনস্টল করে (ইন্টারনেট লাগে) | Python ইনস্টল করবে কি না |
| নিজস্ব Python পরিবেশ (`.venv`) আর প্যাকেজ বসায় | — |
| AI মডেল পরীক্ষা করে (ZIP-এ থাকলে আর নামায় না) | — |
| নতুন গোপন কী দিয়ে `.env` বানায় (আগে থাকলে **কখনো বদলায় না**) | — |
| ডাটাবেস বানায় | প্রথম অ্যাডমিনের ইউজারনেম আর পাসওয়ার্ড |
| অফিসের অন্য কম্পিউটার থেকে খোলার ব্যবস্থা (শুধু এই নেটওয়ার্কের জন্য ফায়ারওয়াল খোলে) | চালু করবে কি না |
| পিসি চালু হলেই অ্যাপ চালু | চালু করবে কি না |
| প্রতি রাত ২টায় ব্যাকআপ | চালু করবে কি না |
| ডেস্কটপে **Gate Face** শর্টকাট | — |

5. শেষে অ্যাপ চালু হয়ে ব্রাউজারে খুলে যাবে। অ্যাডমিন দিয়ে লগইন করে নিচের **ধাপ ৮** থেকে কাজ শুরু করুন।

> ⚠️ ইনস্টলের পর **`.env` ফাইলের একটি কপি** পেনড্রাইভে রাখুন (নিচে ধাপ ৩-এর সতর্কতা দেখুন)।

**অটো-স্টার্ট সম্পর্কে:** `scripts\nssm.exe` থাকলে (বা NSSM ইনস্টল করা থাকলে) ইনস্টলার আসল Windows সার্ভিস বসায়, যা কেউ লগইন না করলেও চলে। না থাকলে এমন ব্যবস্থা বসায় যাতে এই Windows ব্যবহারকারী সাইন-ইন করলেই অ্যাপ চালু হয়। গেটের পিসিতে Windows-এর **স্বয়ংক্রিয় সাইন-ইন** চালু রাখলে দুটোর ফল একই।

**ইন্টারনেট ছাড়া ইনস্টল:** ডেভেলপার `-Offline` দিয়ে ZIP বানালে প্যাকেজও ZIP-এর ভেতরে থাকে। তখন নতুন পিসিতে শুধু Python আগে থেকে ইনস্টল থাকলেই চলে।

নিচের ধাপগুলো হাতে ইনস্টল করার জন্য, অথবা ইনস্টলার কোথাও আটকে গেলে কারণ বোঝার জন্য।

## ZIP বানানো (ডেভেলপারের জন্য)

সব পরিবর্তন commit করার পর প্রজেক্ট ফোল্ডারে চালান:

```powershell
.\scripts\build_release.ps1            # dist\GateFace-<তারিখ>-<commit>.zip (কোড + মডেল, প্রায় ৭০ MB)
.\scripts\build_release.ps1 -Offline   # সাথে প্যাকেজও (ইন্টারনেট ছাড়া ইনস্টলের জন্য)
```

ZIP-এ শুধু git-এ commit করা ফাইল আর মডেল থাকে। `.env`, `data\`, `backups\` বা `.venv\` কখনো ঢোকে না, ভুল করে commit হয়ে থাকলেও স্ক্রিপ্ট ZIP বানাতে অস্বীকার করে।

## যা লাগবে

- Windows 10 বা 11 পিসি, যা সবসময় চালু থাকবে
- Python **3.11 বা 3.12** ([python.org](https://www.python.org/downloads/) থেকে। ইনস্টলের সময় "Add Python to PATH" টিক দিন।)
- ক্যামেরা বা NVR যে নেটওয়ার্কে আছে, পিসিও সেই নেটওয়ার্কে থাকতে হবে
- প্রথমবার মডেল ও প্যাকেজ নামাতে ইন্টারনেট (পরে আর লাগে না)

## ধাপ ১: প্যাকেজ ইনস্টল

```powershell
cd D:\projetcs\gate

`Activate.ps1` চালাতে "running scripts is disabled" ত্রুটি এলে একবার চালান:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## ধাপ ২: AI মডেল নামানো

```powershell
python -m tools.download_models
```

এটা `models\` ফোল্ডারে তিনটি মডেল নামায়: মুখ খোঁজার, মুখ চেনার আর মানুষ বা গাড়ি শনাক্তের (মোট প্রায় ৭৫ MB)।

## ধাপ ৩: নিরাপত্তা কী (`.env` ফাইল)

```powershell
python -m tools.generate_env
```

এটা `.env` ফাইল বানায় এবং তাতে দুটি নতুন গোপন কী বসায়:

- `SECRET_KEY`: লগইন সেশন সুরক্ষিত রাখে।
- `FERNET_KEY`: ক্যামেরার পাসওয়ার্ড আর মুখের ডাটা এনক্রিপ্ট করে।

> ⚠️ **`.env` ফাইলের একটি কপি নিরাপদ জায়গায় রাখুন** (যেমন পেনড্রাইভে, আলমারিতে)। `FERNET_KEY` হারালে সেভ করা ক্যামেরা পাসওয়ার্ড আর সব মুখের নিবন্ধন আর পড়া যাবে না, সবাইকে আবার নিবন্ধন করতে হবে।

ডিফল্ট বা দুর্বল কী থাকলে অ্যাপ চালু হতে অস্বীকার করবে। এটা ইচ্ছাকৃত নিরাপত্তা ব্যবস্থা।

## ধাপ ৪: প্রথম অ্যাডমিন অ্যাকাউন্ট

```powershell
python -m app.createadmin
```

ইউজারনেম আর অন্তত ১২ অক্ষরের পাসওয়ার্ড দিন। পরের অ্যাকাউন্টগুলো ওয়েব থেকেই বানানো যাবে (**ব্যবহারকারী** পেজ)।

## ধাপ ৫: চালু করে দেখা

```powershell
.\scripts\run.ps1
```

ব্রাউজারে খুলুন: **http://127.0.0.1:8090/login**

বাংলায় দেখতে উপরের ডান কোণে **বাংলা** বোতামে ক্লিক করুন। বন্ধ করতে PowerShell-এ `Ctrl + C` চাপুন।

## ধাপ ৬: অন্য কম্পিউটার বা মোবাইল থেকে দেখা (ঐচ্ছিক)

ডিফল্টভাবে অ্যাপ শুধু এই পিসি থেকেই খোলা যায়। গার্ডরুমের অন্য কম্পিউটার থেকে দেখাতে:

1. `.env` ফাইলে `HOST=127.0.0.1` বদলে `HOST=0.0.0.0` করুন।
2. Windows Firewall-এ পোর্ট 8090 শুধু অফিসের নেটওয়ার্কের জন্য খুলুন (অ্যাডমিন PowerShell-এ, `192.168.1.0/24`-এর জায়গায় আপনার নেটওয়ার্ক দিন):

   ```powershell
   New-NetFirewallRule -DisplayName "Gate Face" -Direction Inbound -Protocol TCP -LocalPort 8090 -RemoteAddress 192.168.1.0/24 -Action Allow
   ```
3. অন্য কম্পিউটার থেকে খুলুন: `http://<এই-পিসির-IP>:8090`

> ⚠️ রাউটারে পোর্ট ফরওয়ার্ড করে এই অ্যাপ **কখনো ইন্টারনেটে খুলবেন না।**

## ধাপ ৭: Windows সার্ভিস (পিসি চালু হলেই অ্যাপ চালু)

প্রতিদিন হাতে চালু না করে Windows সার্ভিস হিসেবে বসান। পিসি রিস্টার্ট হলে বা অ্যাপ বন্ধ হয়ে গেলে নিজেই আবার চালু হবে।

1. [nssm.cc/download](https://nssm.cc/download) থেকে NSSM নামিয়ে আনজিপ করুন, যেমন `C:\Tools\nssm`।
2. **Run as administrator** দিয়ে PowerShell খুলে প্রজেক্ট ফোল্ডারে যান।
3. চালান:

   ```powershell
   .\scripts\install_service_windows.ps1 -NssmPath "C:\Tools\nssm\win64\nssm.exe"
   ```
4. কোন Windows অ্যাকাউন্টে চলবে জিজ্ঞেস করলে `.\username` আকারে একটি লোকাল অ্যাকাউন্ট দিন। `SYSTEM` দেবেন না। ওই অ্যাকাউন্টের প্রজেক্ট ফোল্ডার পড়ার আর `data\` ফোল্ডারে লেখার অনুমতি থাকতে হবে।

সার্ভিসের নাম `GateFace`। পরে যা যা করা যায়:

| কাজ | কমান্ড |
|---|---|
| অবস্থা দেখা | `Get-Service GateFace` |
| রিস্টার্ট | `Restart-Service GateFace` |
| লগ দেখা | `data\logs\service-error.log` |
| সার্ভিস সরানো | `.\scripts\install_service_windows.ps1 -Uninstall -NssmPath "C:\Tools\nssm\win64\nssm.exe"` |

## ধাপ ৮: চালু হওয়ার পর

1. অ্যাডমিন দিয়ে লগইন করুন।
2. ক্যামেরা যোগ করুন: [ক্যামেরা গাইড](02-cameras-hikvision.md)।
3. গার্ডদের জন্য অ্যাকাউন্ট বানান (**ব্যবহারকারী** পেজ, ভূমিকা "নিরাপত্তা প্রহরী")।
4. কর্মীদের মুখ নিবন্ধন করুন: [দৈনন্দিন ব্যবহার](03-user-guide.md), "মুখ নিবন্ধন" অংশ।
5. নজরদারির নিয়ম আঁকুন: [নিয়ম গাইড](04-rules.md)।
6. প্রতিদিনের ব্যাকআপ চালু করুন: [রক্ষণাবেক্ষণ](05-maintenance.md), "ব্যাকআপ" অংশ।
