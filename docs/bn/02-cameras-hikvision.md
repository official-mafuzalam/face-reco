# ২. ক্যামেরা যোগ করা (Hikvision NVR)

আপনার Hikvision IP ক্যামেরাগুলো NVR-এ যুক্ত আছে আর মনিটরে দেখা যায়, তাই সেটা যেমন আছে তেমনই থাকবে। গেট ফেস NVR থেকে **RTSP** দিয়ে একই ভিডিওর আলাদা একটা কপি নেয়, এতে NVR-এর রেকর্ডিং বা মনিটরে কোনো প্রভাব পড়ে না।

## ধাপ ১: তথ্য সংগ্রহ

| কী লাগবে | কোথায় পাবেন | উদাহরণ |
|---|---|---|
| NVR-এর IP | NVR মেনু → Configuration → Network → TCP/IP | `192.168.1.100` |
| RTSP পোর্ট | Configuration → Network → Port (সাধারণত 554) | `554` |
| ক্যামেরার চ্যানেল | লাইভ ভিউতে D1, D2, D3… | D3 = চ্যানেল ৩ |
| ইউজারনেম ও পাসওয়ার্ড | নিচে দেখুন | `gateapp` |

**আলাদা ইউজার বানান।** NVR-এ **Configuration → User Management**-এ একজন নতুন ইউজার (যেমন `gateapp`) বানান, যার শুধু **Live View** অনুমতি থাকবে। admin পাসওয়ার্ড এই অ্যাপে দেবেন না।

## ধাপ ২: RTSP ঠিকানা বানানো

```
rtsp://NVR_IP:554/Streaming/Channels/<চ্যানেল><স্ট্রিম>
```

- স্ট্রিম `01` = **Main stream**: পূর্ণ মান, CPU বেশি লাগে
- স্ট্রিম `02` = **Sub stream**: কম মান, CPU কম লাগে

| ক্যামেরা | Main stream | Sub stream |
|---|---|---|
| D1 | `/Streaming/Channels/101` | `/Streaming/Channels/102` |
| D2 | `/Streaming/Channels/201` | `/Streaming/Channels/202` |
| D3 | `/Streaming/Channels/301` | `/Streaming/Channels/302` |
| D10 | `/Streaming/Channels/1001` | `/Streaming/Channels/1002` |

**কোনটা কখন:**

- **গেটের ক্যামেরা (মুখ চেনার জন্য):** Main stream (`…01`)। মুখ চিনতে বড় ছবি লাগে, মুখ কমপক্ষে ৮০ পিক্সেল চওড়া হতে হবে।
- **কারখানার অন্য ক্যামেরা (নজরদারি):** Sub stream (`…02`)। এতেই যথেষ্ট।

NVR ছাড়া ক্যামেরার নিজের IP দিয়েও যোগ করা যায়, ঠিকানার ধরন একই:
`rtsp://192.168.1.64:554/Streaming/Channels/101`

## ধাপ ৩: সংযোগ পরীক্ষা

অ্যাপে যোগ করার আগে প্রজেক্ট ফোল্ডারে PowerShell খুলে পরীক্ষা করুন (`PASSWORD`-এর জায়গায় আসল পাসওয়ার্ড দিন):

```powershell
.\.venv\Scripts\python.exe -m app.camera.probe "rtsp://gateapp:PASSWORD@192.168.1.100:554/Streaming/Channels/302" --out test.jpg
```

সফল হলে এমন দেখাবে:

```
Resolution: 704x576
FPS: 15.00
Frame saved to: test.jpg
```

`test.jpg` খুলে দেখুন সঠিক ক্যামেরার ছবি এসেছে কি না। দেখা হয়ে গেলে ফাইলটি মুছে দিন।

## ধাপ ৪: অ্যাপে যোগ করা

অ্যাডমিন দিয়ে লগইন করে **ক্যামেরা → ক্যামেরা যোগ করুন**-এ যান।

| ঘর | কী লিখবেন |
|---|---|
| ক্যামেরার নাম | বোঝার মতো নাম, যেমন "গোডাউন পেছন" |
| গেট | গেটের ক্যামেরা হলে গেটের নাম ("প্রধান গেট")। অন্য ক্যামেরায় এলাকার নাম ("কারখানা") |
| দিক | গেটের ক্যামেরা: ঢোকার পথে হলে **IN**, বের হওয়ার পথে হলে **OUT**। অন্য ক্যামেরায় যেকোনো একটি। |
| উৎস | `rtsp://gateapp@192.168.1.100:554/Streaming/Channels/302`। **পাসওয়ার্ড ছাড়া** লিখুন। |
| পাসওয়ার্ড | NVR ইউজারের পাসওয়ার্ড। এখানে আলাদা করে দিলে `@` বা `#` চিহ্ন থাকলেও সমস্যা হয় না, আর এটা এনক্রিপ্ট হয়ে সেভ হয়। |
| সক্রিয় | ✓ |
| এই ক্যামেরা ব্যবহার হবে | নিচের টেবিল দেখুন |

| ক্যামেরার ধরন | ফেস রিকগনিশন (গেট লগ) | নজরদারি (ঘটনা ও নিয়ম) |
|---|---|---|
| গেটের ক্যামেরা | ✓ | ইচ্ছামতো |
| গোডাউন, স্টোর, দেয়াল, পার্কিং | ✗ **বন্ধ রাখুন** | ✓ |

> গেটের বাইরের ক্যামেরায় ফেস রিকগনিশন চালু রাখলে সেটাও IN/OUT লিখবে, ফলে হাজিরার হিসাব ভুল হবে।

**সংরক্ষণ** চাপলে কয়েক সেকেন্ডের মধ্যে ক্যামেরা তালিকায় **online** দেখাবে এবং ছোট ছবি আসবে।

**একই ক্যামেরা দুই কাজে:** গেটের ক্যামেরা দিয়ে মুখ চেনা আর নজরদারি দুটোই করতে চাইলে, একই চ্যানেল দুবার যোগ করতে পারেন:

- Main stream (`…01`): শুধু ফেস রিকগনিশন।
- Sub stream (`…02`): শুধু নজরদারি।

এতে CPU-র ব্যবহার সবচেয়ে কম থাকে।

## ধাপ ৫: NVR-এ সুপারিশকৃত সেটিং

NVR মেনু → **Configuration → Video/Audio** → চ্যানেল বাছাই করে **Sub Stream**-এ:

| সেটিং | মান |
|---|---|
| Video Encoding | **H.264** (H.265+ বা H.264+ "Smart Codec" বন্ধ) |
| Resolution | 640×480 বা 704×576 |
| Frame Rate | ১০–১৫ fps |
| Bitrate | 512–1024 Kbps |

Smart Codec চালু থাকলে মাঝে মাঝে ছবি ভাঙা, সবুজ বা ধূসর আসতে পারে।

## সমস্যা হলে

| ত্রুটি বা লক্ষণ | সম্ভাব্য কারণ ও সমাধান |
|---|---|
| `Unable to open source` | IP বা পোর্ট ভুল, অথবা পিসি থেকে NVR-এ পৌঁছানো যাচ্ছে না। `ping 192.168.1.100` দিয়ে দেখুন। |
| `401` / `Unauthorized` | ইউজারনেম বা পাসওয়ার্ড ভুল, অথবা ইউজারের Live View অনুমতি নেই |
| `No frame received` | চ্যানেল নম্বর ভুল, অথবা ওই চ্যানেলে ক্যামেরা নেই |
| ক্যামেরা বারবার offline হয় | নেটওয়ার্ক দুর্বল। Sub stream বা কম bitrate দিন। অ্যাপ নিজে থেকে আবার সংযোগের চেষ্টা করে। |
| ছবি ভাঙা বা সবুজ | Sub stream-এ H.264 দিন, Smart Codec বন্ধ করুন |
| ভুল পাসওয়ার্ডে বারবার চেষ্টা করার পর NVR ইউজার লক | NVR-এ অবৈধ লগইন লক কয়েক মিনিট পর খোলে, অথবা অ্যাডমিন দিয়ে আনলক করুন |

## কয়টি ক্যামেরা যোগ করবেন

এই পিসিতে নজরদারি **১–৪টি** ক্যামেরায় ভালো চলে। কারখানায় বেশি ক্যামেরা থাকলে সবচেয়ে ঝুঁকিপূর্ণ জায়গাগুলো আগে বেছে নিন:

1. প্রধান গেট
2. গোডাউন বা স্টোর রুমের দরজা
3. পেছনের দেয়াল বা বাউন্ডারি
4. লোডিং এরিয়া

ক্যামেরা যোগ করার পর [নজরদারির নিয়ম](04-rules.md) আঁকুন।
